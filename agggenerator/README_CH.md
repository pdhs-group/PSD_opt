# agggenerator 算法说明（中文）

## 1. 文档目的

本文档面向需要理解 `agggenerator` 中核心算法的研究人员与开发者，重点说明以下两个模块的设计思想与实现流程：

- `src/agggenerator/mptsa2d.py`
- `src/agggenerator/material_mix.py`

前者负责在二维离散格点上生成具有目标分形维数的 aggregate 基本几何；后者在保持几何形状不变的前提下，进一步按照给定体积分数与目标混合度，对已占据格点进行两相材料填充。两者组合后，可以得到同时具备“几何分形结构”和“相分布统计特征”的颗粒模型。

## 2. 总体建模思路

整个生成过程可以分为两个层次：

1. 几何层
   先在二维规则格点上生成一个二值占据场 `grid ∈ {0,1}^{H×W}`。其中 `1` 表示 aggregate 中被固体占据的格点，`0` 表示空白区域。该阶段主要控制 aggregate 的尺度增长行为和分形维数。
2. 材料层
   在固定的几何占据场上，为每一个被占据格点分配材料 A 或材料 B，得到 `labels ∈ {-1,0,1}^{H×W}`。其中 `-1` 表示空白格点，`0` 表示材料 A，`1` 表示材料 B。该阶段主要控制总体组分比例与局域混合程度。

因此，这套方法本质上是一个“先生成形状，再生成成分”的两阶段框架。几何复杂性由分形生长决定，材料混合性由统计物理式的交换过程决定。

## 3. `mptsa2d.py`：基于目标分形维数的二维格点 aggregate 生成

### 3.1 核心目标

该模块的目标是在二维四邻域格点上生成一个连通 aggregate，使其整体尺度统计满足典型分形关系

```text
Rg ~ N^(1 / Df)
```

其中：

- `N` 表示已占据格点数
- `Rg` 表示回转半径（radius of gyration）
- `Df` 表示目标分形维数

代码中用 `estimate_fractal_dimension_2d` 对生成结果做对数线性回归：

```text
log(Rg) = (1 / Df) * log(N) + const
```

从而得到实际生成结构的估计分形维数。

### 3.2 参数对象

几何生成由 `MPTSALatticeParams2D` 控制，关键参数包括：

- `Np`：目标占据格点数
- `Df`：目标分形维数
- `k`：尺度律中的前因子
- `max_attempts`：单次放置时允许的最大尝试次数
- `seed`：随机种子
- `fill_hole`：是否在生长结束后执行“小孔填补 + 等量边界补偿删除”
- `hole_area_max`：被定义为“小孔”的最大面积
- `compensate_alpha`、`compensate_beta`：补偿删除时的评分权重

### 3.3 基本生长机制

`generate_mptsa_lattice_2d(...)` 从两个相邻种子点开始初始化 aggregate。此后，每一步都执行一次“从已有结构边界继续长出一个新格点”的过程，直到达到目标 `Np`。

其核心步骤如下：

1. 当前 aggregate 的所有占据点坐标记为 `positions`。
2. 根据当前结构相对于目标分形尺度律的偏差，给每个已有格点分配一个径向权重。
3. 按该权重随机选取一个“基点”。
4. 在该基点的四邻域空位置中随机选择一个可放置的新格点。
5. 将新格点加入 aggregate，更新 `positions`、`Ns` 和 `Rgs`。
6. 重复以上过程，直到总占据数达到 `Np`。

这里最关键的是第 2 步和第 3 步：算法不是在全部边界点上均匀生长，而是通过“偏向更外层或更内层”的概率机制，动态调节 aggregate 的紧密程度，从而逼近目标 `Df`。

### 3.4 径向权重的自适应调节

函数 `_compute_radial_weights(...)` 首先计算当前 aggregate 的质心与实际回转半径 `Rg`，然后根据目标尺度关系构造期望回转半径：

```text
Rg_target = a * N^(1 / Df)
```

其中 `a` 是由 `k` 和 `Df` 派生的经验前因子。

接着，代码比较 `Rg_target / Rg`：

- 若该比值大于 1，说明当前结构相对过于紧凑，需要更倾向于在远离质心的位置继续生长。
- 若该比值小于 1，说明当前结构相对过于松散，需要减弱向外生长偏置。

这种偏差通过指数 `beta` 作用到每个点的径向距离权重上：

```text
w_i = (r_i + eps)^beta
```

其中 `r_i` 为第 `i` 个占据点到当前质心的距离。这样一来，离质心更远的格点在某些阶段更容易被选为生长基点，aggregate 的外延尺度也随之增大；反之则趋于收缩。这一机制构成了 MPTSA 在离散格点版本中的“分形反馈控制”。

### 3.5 四邻域格点约束

新格点的候选位置仅限于被选中基点的四邻域空格点：

- `(x+1, y)`
- `(x-1, y)`
- `(x, y+1)`
- `(x, y-1)`

因此，生成结果天然满足四邻域连通性，并且适用于后续基于四邻域相互作用的材料混合模型。

### 3.6 回转半径与分形维数估计

函数 `radius_of_gyration_2d(...)` 计算当前点集的回转半径：

```text
Rg = sqrt( (1/N) * Σ_i |r_i - r_cm|^2 )
```

其中 `r_cm` 是质心坐标。

在整个生长过程中，代码持续记录：

- `Ns`：每一步的占据数
- `Rgs`：对应的回转半径

随后用 `estimate_fractal_dimension_2d(...)` 对 `log(Rg)` 与 `log(N)` 做线性拟合，进而反推出实际的 `Df`。这一步为后续筛选或参数校准提供了定量依据。

### 3.7 二值网格输出

生长完成后，函数 `_to_min_bounding_grid(...)` 会将无序坐标集合转换为最小外接矩形内的紧致二值网格：

- 输出 `grid` 的类型为 `uint8`
- `grid[y, x] = 1` 表示该位置被 aggregate 占据
- 同时返回 `origin = (x_min, y_min)`，用于把裁剪后的局部坐标映射回原始全局格点坐标

这一步把“点集表示”转成了更适合图像处理和后续材料分配的“数组表示”。

### 3.8 小孔填补与等量边界补偿

如果 `fill_hole=True`，代码会执行 `fill_small_holes_and_compensate(...)`，这是一个非常实用的后处理步骤。它包含两个子过程。

#### 3.8.1 小孔识别与填补

`_fill_holes_inplace(...)` 使用外背景 flood-fill 的方式识别内部孔洞：

1. 先对原二值图做一圈零填充。
2. 从外层边框上的背景像素出发，进行四邻域泛洪，标记所有与外界连通的背景区域。
3. 未被标记、且值为 0 的连通背景区域即内部孔洞。
4. 对面积不超过 `area_max` 的小孔进行填补。

这一过程可以消除生成过程带来的局部空腔，使结构更接近一些实际颗粒的内部实心特征。

#### 3.8.2 等量边界删除补偿

填补小孔会增加 aggregate 的占据数。为了保持总体格点数近似不变，代码随后执行 `_delete_boundary_pixels(...)`，从外边界删除与填补数量相同的格点。

删除时并非任意去掉边界像素，而是采用了三重约束：

1. 候选点必须是边界点。
2. 优先考虑“叶子点”，即四邻域度数为 1 的细枝末端。
3. 删除该点之后，剩余 aggregate 必须仍保持全局四邻域连通。

在满足以上拓扑约束的候选点中，算法再定义一个评分函数：

```text
score = alpha * r^2 - beta * exposure
```

其中：

- `r^2` 是候选点到当前质心的平方距离
- `exposure` 是其朝向背景或边界外的暴露邻接数

算法优先删除评分较小的点。直观上，这倾向于删除更“暴露”、更接近外缘、同时尽量不破坏主体结构的格点，从而在补孔之后保持 aggregate 的整体外形与连通性。

### 3.9 几何算法小结

`mptsa2d.py` 的方法可以概括为：

- 用受目标分形维数约束的随机生长规则生成连通格点团簇；
- 用回转半径尺度律来调节结构疏密；
- 用可选的“补孔 + 等量删除”后处理来修正局部几何缺陷；
- 最终输出适合进一步材料赋值的紧致二值网格。

从算法性质上看，它属于“受统计尺度律约束的离散随机生长模型”。

## 4. `material_mix.py`：固定几何上的两相材料混合与 MAS 控制

### 4.1 核心目标

在给定 aggregate 几何 `grid` 后，该模块需要解决的问题是：

1. 使材料 A 的总体占比尽量等于给定 `frac_A`
2. 使材料空间混合程度尽量逼近给定目标 `target_MAS`
3. 在整个过程中不改变 aggregate 的几何结构

因此，这一阶段的自由度不是“格点是否被占据”，而是“每个已占据格点属于 A 还是 B”。

### 4.2 参数对象

材料混合由两个参数对象控制：

#### `MaterialMixParams`

- `frac_A`：材料 A 的目标体积分数
- `target_MAS`：目标混合度
- `tol_MAS`：允许误差
- `window`、`stride`：局域混合统计时的滑动窗口大小与步长
- `min_occupancy_ratio`：窗口最小有效占据率
- `lambda_min`、`lambda_max`：相互作用强度搜索区间
- `sweeps_per_eval`：每次评估前执行的 MCMC sweep 数
- `max_bisect`：二分搜索最大迭代次数
- `temperature`：Metropolis 接受准则中的温度
- `seed`：随机种子

#### `MASPhysicalParams`

这一对象用于定义 MAS 公式中上下界的物理参数，包括：

- `dc`、`dSi`、`dcSi`
- `Cc`、`CSi`
- `transmission_weights`

如果不提供额外物理模型，代码会退化到较简单的像素式上、下界定义。

### 4.3 精确组分约束

函数 `assign_materials_with_target_mas(...)` 首先统计 aggregate 中总占据格点数 `M`，然后按

```text
nA = round(frac_A * M)
nB = M - nA
```

确定 A、B 两相的精确格点数。随后通过一次随机排列，将这 `M` 个已占据位置中的前 `nA` 个赋值为 A，剩余赋值为 B。

因此，该实现不是在期望意义上满足体积分数，而是在整数格点层面严格满足材料计数约束。这一点对于后续做可重复数据生成和统计分析非常重要。

### 4.4 固定几何上的图表示

为了在材料交换时只考虑真实相邻的 occupied 格点，代码把 aggregate 视为四邻域图：

- 每个已占据格点是一个节点
- 若两个 occupied 格点在上下左右方向相邻，则在它们之间连一条边

函数 `_build_neighbors_4(...)` 构建这一邻接关系。后续的能量计算和 MCMC 交换都在这张图上进行，而不是在完整矩阵上盲目扫描。

### 4.5 基于同相邻接数的 Ising 风格能量

代码采用如下能量形式：

```text
E = -lambda * S
```

其中 `S` 为所有四邻域边中“同材料相邻”的配对数。

因此：

- 当 `lambda > 0` 时，系统倾向于增加同相邻接，表现为材料团聚、分离增强；
- 当 `lambda < 0` 时，系统倾向于减少同相邻接，表现为异相交错、混合增强；
- `lambda = 0` 附近对应近似随机混合。

这是一种典型的 Ising/Potts 风格局域相互作用模型，但这里不改变格点占据状态，只交换材料标签。

### 4.6 保持总体组分不变的交换式 MCMC

函数 `_mcmc_exchange(...)` 采用交换式的 Metropolis Monte Carlo：

1. 从当前 A 相格点集合中随机选一个点 `u`
2. 从当前 B 相格点集合中随机选一个点 `v`
3. 提议交换两者材料标签
4. 计算交换前后同相邻接数变化 `ΔS`
5. 由 `ΔE = -lambda * ΔS` 得到能量变化
6. 按照 Metropolis 准则决定接受或拒绝

接受概率为：

```text
P(accept) = 1,                 if ΔE <= 0
P(accept) = exp(-ΔE / T),      if ΔE > 0
```

其中 `T` 是温度参数。

这种“交换而不是翻转”的设计有两个重要优点：

- 全局 A/B 总数始终严格不变
- 材料结构会逐步向与 `lambda` 相适应的空间相关状态演化

### 4.7 MAS 的统计定义

对当前材料分布，代码通过 `_evaluate_mas_on_labels(...)` 计算 Mischgüte（MAS）。实现采用如下归一化形式：

```text
MAS = log(σ0^2 / σ^2) / log(σ0^2 / σz^2)
```

其中：

- `σ^2`：当前材料分布在局域窗口下观测到的方差
- `σ0^2`：完全分离状态对应的上界方差
- `σz^2`：理想均匀随机混合状态对应的下界方差

这样定义后，MAS 被裁剪在 `[0, 1]` 区间内：

- 越接近 `0` 表示越偏分离
- 越接近 `1` 表示越偏理想混合

### 4.8 局域方差 `σ^2` 的计算

`_sigma2_window_variance(...)` 使用滑动窗口统计每个局域区域内 A 相比例，并计算这些局域比例的总体方差：

1. 在 `window × window` 窗口中统计 occupied 数与 A 相数
2. 仅保留占据率高于 `min_occupancy_ratio` 的窗口
3. 对每个有效窗口计算局域 A 相比例
4. 对所有有效窗口上的局域比例计算总体方差，得到 `σ^2`

为了提高效率，代码使用积分图（integral image）来做窗口求和，使单个窗口统计可在常数时间内完成。这使得 MAS 评估在大量窗口上仍保持较高效率。

### 4.9 上界 `σ0^2` 与下界 `σz^2`

#### 上界 `σ0^2`

`_sigma0_upper_bound(...)` 默认使用二相系统的简单二项式上界：

```text
σ0^2 = X_A * (1 - X_A)
```

其中 `X_A` 为全局 A 相比例。

如果提供了 `transmission_weights`，代码也支持一个加权传输模型来定义更物理化的上界。

#### 下界 `σz^2`

`_sigmaz_lower_bound(...)` 对每个窗口统计平均 occupied 数 `N̄`，再构造

```text
σz^2 = [X_A (1 - X_A) / N̄] * geom_factor * size_factor
```

其中：

- `geom_factor = (dc * dSi / dcSi)^2`
- `size_factor = 1 + (1 - X_A) * Cc^2 + X_A * CSi^2`

这一形式体现的是“理想随机均匀混合下，局域组成涨落随着窗口采样粒子数增加而减小”的统计规律。

### 4.10 用二分法搜索满足目标 MAS 的相互作用强度

仅靠指定 `lambda` 无法直接保证最终 MAS 等于目标值，因此代码在 `assign_materials_with_target_mas(...)` 中引入了“`lambda` 二分搜索 + MCMC 热化”的外层控制。

其流程如下：

1. 取 `lambda_min` 与 `lambda_max` 作为初始搜索区间。
2. 分别在区间端点附近进行少量交换，估计对应的 `MAS_low` 与 `MAS_high`。
3. 若两端顺序与预期不一致，则交换区间端点，确保 MAS 关于 `lambda` 在当前区间内呈单调顺序。
4. 取中点 `lambda_mid`，执行若干 sweep 的交换演化。
5. 计算当前 `MAS_mid`。
6. 根据 `MAS_mid` 相对目标值的大小，更新二分区间。
7. 重复以上过程，直到达到 `tol_MAS` 或超过 `max_bisect`。

这意味着该模块并不是直接“指定某个混合态”，而是通过调节局域相互作用强度，让系统自组织到目标混合度附近。

### 4.11 输出结果

材料混合完成后，函数返回：

- `labels`：完整材料标签图，空白格点为 `-1`，A 相为 `0`，B 相为 `1`
- `stats`：包含 `N_total`、`nA`、`nB`、`frac_A`、`lambda_used`、`MAS`、`sigma2`、`sigma0_sq`、`sigmaz_sq`、`window`、`stride` 等统计量

这些输出既可直接用于可视化，也适用于后续的物理模拟或机器学习数据集构建。

## 5. 两个模块之间的接口关系

这两个模块的衔接关系非常明确：

1. `mptsa2d.py` 输出几何占据场 `grid`
2. `material_mix.py` 以该 `grid` 为输入，只在 occupied 区域上分配 A/B 材料
3. 因此几何分形特征和材料统计特征可以分别控制，再组合成最终样本

这种分层设计有明显优点：

- 几何与材料参数可分开扫描
- 便于分析各参数对最终结构的独立影响
- 适合生成结构化训练数据集

## 6. 方法特征与适用范围

从方法论角度看，这套实现具有以下特点：

- 属于离散格点模型，适合与基于格点的后续模拟器直接对接
- 分形维数是通过生长偏置间接控制，而不是通过封闭解析构造直接给定
- 材料混合度是通过局域统计量和 MCMC 反演得到，而不是手工拼接得到
- 采用四邻域定义，因此连通性、边界和相互作用都具有清晰的离散拓扑意义
- 多处关键计算使用了 `numba` 或积分图加速，适合批量生成数据

同时也应注意其假设前提：

- 当前几何生长与材料相互作用都建立在二维格点和四邻域连接上
- MAS 关于 `lambda` 的单调性是在给定搜索区间内默认成立的
- 当网格尺寸过小、窗口过大时，MAS 统计可能失效，因此窗口参数需要与 grid 尺寸匹配

## 7. 总结

`mptsa2d.py` 与 `material_mix.py` 共同构成了一套完整的二维 aggregate 生成框架：

- 前者解决“形状如何长成目标分形结构”的问题；
- 后者解决“在既定形状上如何实现目标材料配比与混合度”的问题。

二者结合后，能够生成同时具有几何复杂性与材料非均匀性的颗粒样本。这类样本尤其适合用于：

- 离散颗粒体系的数值模拟输入
- 材料微结构统计分析
- 基于结构参数到物理响应的机器学习训练数据构建

如果后续需要把这套方法扩展到三维、改为八邻域或更复杂相互作用模型，当前代码的模块划分也提供了较清晰的扩展基础。
